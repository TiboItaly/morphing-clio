Morphing des visages — Anniversaire Clio

Transformation continue entre deux photos, calculée entièrement dans votre navigateur. Aucune image n'est envoyée sur un serveur.

Paramètre du morphing — 0 % photo 1 → 100 % photo 250 %

L'animation démarre dès que les deux photos sont chargées : la transformation s'étale sur 6 secondes par étape, en va-et-vient. « Enregistrer la vidéo » capture un aller-retour complet (12 secondes) et propose le téléchargement.

Les neuf repères

    Sur chaque photo, vérifiez les neuf repères : leur précision détermine la qualité du morphing. La photo est d'abord cadrée sur le visage ; glissez le fond ou utilisez la molette pour corriger le cadrage.

    Glissez un numéro pour l'ajuster ; glissez ailleurs pour recadrer la photo ; molette pour zoomer.
